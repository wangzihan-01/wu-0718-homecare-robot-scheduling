The imitation-learning design draws on the general use of optimizer demonstrations in [SADCHER](https://github.com/jakbichler/Sadcher). [JobShopLib](https://github.com/Pabloo22/job_shop_lib) informed the choice of a shared simulator and interchangeable planners. The project uses its own implementation and synthetic task data.
